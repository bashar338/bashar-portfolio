# Bashar Zahid — Portfolio

موقع بورتفوليو ساكن (HTML/CSS/JS) لمحرر فيديو ومصمم موشن غرافيك.

## ربط الفيديوهات

ملفات الفيديو الكبيرة محفوظة محليًا ولا تُرفع إلى GitHub؛ حد الرفع لكل ملف هو 100MB. استضف المقاطع على خدمة مناسبة، ثم حدّث روابط `video` داخل `projectData` في `script.js` بروابط MP4 مباشرة. تُعدَّل روابط المقاطع الموجودة في قوائم `clips` بالطريقة نفسها. إلى أن تُضاف الروابط، تظهر رسالة واضحة عند محاولة تشغيل مقطع.

```js
const projectData = {
  afterlight: {
    // ...
    video: 'https://your-video-host.example/afterlight.mp4'
  }
};
```

أبقِ الملفات محليًا داخل `media/` للمعاينة على جهازك؛ هذا المجلد مستثنى من Git.

## النشر

الموقع ملفات static ويُنشر عبر GitHub Pages من فرع `main` ومجلد الجذر (`/`). يتضمن المستودع ملفات HTML وCSS وJavaScript والخطوط والصور، ولا يتضمن ملفات الفيديو الكبيرة أو مجلد `dist`.
